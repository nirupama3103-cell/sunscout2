# SunScout ⛅ — Summer Activities for Bay Area Kids

**Live site:** https://sunscout2.vercel.app

SunScout helps Bay Area families discover free and paid summer activities for kids across 7 cities.

## 📁 Tabs

*   🆓 Free — Parks, Libraries, Splash Pads, Storytime
*   🎟️ Paid — YMCA, STEM, Camps, Ballet, Coding
*   🏛️ Indoor — Museums, Pools, Workshops
*   🌳 Outdoor — Hiking, Farms, Petting Zoos
*   📅 Weekend — Markets, Festivals, Train Rides

## 🧠 Smart Features

*   Weather alerts · Age filters · Surprise Me · Live data · Maps
