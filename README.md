# 🌤️ SunScout

**Summer Activity Discovery for Bay Area Families**

SunScout helps Bay Area parents find free and paid summer activities for kids — from STEM camps and library storytimes to petting zoos and splash pads.

🔗 **Live App:** https://sunscout2.vercel.app

## 🏙️ Cities Covered
Sunnyvale · San Jose · Cupertino · Mountain View · Palo Alto · Saratoga · Fremont

## ✨ Features
- 5 activity tabs: Free, Paid, Indoor, Outdoor, Weekend
- Age filters (Infant to Teen)
- Plan My Day wizard
- Weather alerts
- Save favorites & notes (device only)
- 7 Bay Area cities
